## 1. 决策记录

产品负责人在 PR #64 的概念对比、16 px 初审和风险说明交付后指示继续开发。因此本轮把 A“结构化 L”和 `#5B5FF5` 记录为 **RC1 输入**。该决定允许像素校正和主题变体开发，不代表最终商标批准、商标可注册性意见或公开发行许可。

## 2. 本轮交付

1. 浅色环境彩色母版：品牌靛蓝底、白色主 L、中靛蓝次级格子；
2. 深色环境彩色母版：深墨色底、白色主 L、亮靛蓝次级格子；
3. 深色与浅色单色字形：透明画布，只保留最稳定的五单元 L；
4. 静态高对比回退：纯黑底与纯白 L，不依赖灰度或颜色差异；
5. 16、20、24、32、48、64、128、256 px 原生 SVG；
6. 与原生尺寸一一对应的 PNG 渲染产物；
7. 主题与尺寸同屏评审板。

## 3. 像素校正规则

- 16/20/24 px 使用整数坐标、实心路径和 0–1 px 内部圆角效果，避免亚像素边缘削弱 L；
- 32 px 起恢复分级圆角，但所有单元的 x/y/width/height 仍保持整数；
- 每个尺寸保留相同的五主单元与三次级单元拓扑，不通过简单缩放改变空位关系；
- 背景、主 L、次级格子的相对权重保持一致，主 L 不依赖次级色也能成立；
- PNG 必须从同名 SVG 确定性生成，像素尺寸和 alpha 通道由自动检查验证。

| 彩色任务栏/壁纸背景 | 需要真实 Windows 外壳矩阵 | Pending |

静态应用图标与 UI 控件的对比度标准不能完全等同。这里的硬门槛是：在不依赖次级色时，白色或单色 L 仍形成稳定剪影；焦点、选择和交互状态仍必须由正式 UI 的系统颜色与非颜色线索承担。

机器计算的相对亮度对比数据：白色主 L / `#5B5FF5` 为 **4.77:1**，白色主 L / `#171A2B` 为 **17.23:1**，黑白回退为 **21:1**。`#9296F8` 次级格子 / `#5B5FF5` 仅为 **1.80:1**，因此次级格子被明确归类为装饰语义；产品名称和核心 L 的识别不得依赖这组低对比色差。

## 5. 安全、原创与供应链

- 所有源 SVG 只包含 `svg`、`title`、`desc`、`rect`、`path`、`g` 等静态矢量元素；
- 不允许脚本、事件属性、`foreignObject`、滤镜、外链、嵌入位图、网络字体和 `data:` 资源；
- PNG 由仓库内 SVG 本地渲染，不引入第三方品牌素材；
- RC1 继承概念阶段的独立构图过程，但仍未完成覆盖目标发行地区的图形近似与商标数据库检索；
- 在近似性检索关闭前，状态最多为 Conditional Pass。

## 7. 发布门槛与下一步

RC1 可以进入正式 UI Shell 的开发资源目录，但在以下事项关闭前不得升级为 Final：

1. 建立 `LongGrid.App` 后，在 Windows 10/11、100%–300% DPI、浅色/深色/高对比环境检查任务栏、开始菜单、标题栏、快捷方式和应用列表；
2. 建立受测试的资产生成脚本，生成 ICO、MSIX/Store/Square/Splash 资产并验证安全区；
3. 对目标发行地区执行图形近似检索和商标数据库检索，记录查询、日期和判断；
4. 将品牌色转为正式 Design Token，并验证 UI 选择/焦点不依赖品牌色；
5. 产品负责人对外壳实机截图、检索记录和安装包资产最终签字。

下一开发步骤仍遵循产品主线：先用 RC1 建立正式 UI Shell 与 Design Token，不让商标法务或商店素材工作阻塞只读 MVP。
