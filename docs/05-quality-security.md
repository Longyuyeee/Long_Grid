# Long Grid 质量、安全与隐私基线

## 1. 安全边界

Long Grid 会接触桌面文件元数据、快捷方式和窗口信息，属于高信任本地软件。最低承诺：

- 默认以普通用户权限运行。
- 不注入 Explorer 或其他进程，不安装驱动。
- 不绕过 Windows ACL，不静默申请管理员权限。
- 不上传文件内容、文件名、完整路径、窗口标题或缩略图。
- 网络模块可识别、可关闭，不影响核心整理功能。

## 2. 文件操作安全

所有副作用使用统一 `IFileOperationService`：

- 先生成计划并展示源、目标、冲突和预计结果。
- 执行前再次验证路径、权限、磁盘和目标是否变化。
- Windows 适配器优先使用 Shell `IFileOperation`，保留系统进度、错误和回收站语义。
- 优先使用系统可恢复操作；跨卷移动按复制 + 校验 + 删除处理。
- 遇到覆盖、符号链接/重解析点、网络路径和云占位文件时默认停止。
- 操作日志记录匿名 ID 和结果；诊断导出时路径脱敏。
- 单次批量操作要么可完整回滚，要么明确报告部分成功。

MVP 不执行无人确认的自动真实文件移动。规则默认只改变 Long Grid 内的视觉归属；若启用托管目录，真实移动必须逐次或按单条规则明确授权，并记录可撤销边界。

## 3. 配置与迁移

- 每个文档包含 `schemaVersion`。
- 迁移函数是确定性、可测试、不可原地破坏的。
- 始终保留至少一个最近有效备份。
- 加载失败进入安全模式，不用空配置覆盖损坏文件。
- 导入前校验大小、深度、类型、路径和未知扩展。

## 4. 插件边界

插件不进入 MVP。未来若开放：

- 清单声明权限：文件元数据、网络、窗口信息、通知等。
- 默认进程外运行并设资源上限。
- 插件不能直接访问核心配置文件。
- 签名、来源和权限在安装前明确展示。
- 禁止插件模拟“Long Grid 官方”或静默扩大权限。

## 5. 隐私

### 默认收集

无远程遥测。仅保存本地运行所需的配置、布局、规则和轮转日志。

### 可选诊断

- 崩溃报告必须显式选择加入。
- 发送前展示字段和附件。
- 对路径、用户名、窗口标题和文件名做不可逆脱敏。
- 提供数据清除、导出和保留周期说明。

### 若未来提供同步

必须单独完成数据流图、威胁模型、密钥恢复方案、删除机制和跨境/地区合规审查；同步不能成为本地核心功能的前置条件。

## 6. 测试矩阵

### 系统

- Windows 10/11 的受支持版本。
- x64，及产品决定支持时的 ARM64。
- 普通用户、管理员账户、企业策略限制账户。
- Explorer 重启、注销、休眠、快速启动、远程桌面。

### 显示

- 单屏、双屏、三屏。
- 横竖屏混用、负坐标、主屏切换。
- 100%、125%、150%、200%、250%、300%、400% DPI。
- 分辨率切换、HDR、自动隐藏任务栏、投影模式。
- 默认日志和诊断包不得包含显示器 PNP ID、Device Key、adapter LUID、source/target ID、source GDI name、EDID、设备路径、序列号式字段或可关联的路径/拓扑散列。

### 文件系统

- NTFS、本地盘、可移动盘、网络盘。
- OneDrive/其他云占位符。
- 长路径、Unicode、emoji、RTL、大小写差异。
- 失效快捷方式、只读目录、拒绝访问、磁盘满。
- 重解析点、符号链接和循环。

### 交互与无障碍

- 键盘-only、触控、鼠标、多种输入法。
- Narrator、文本缩放、高对比度、减少动画。
- 全局快捷键冲突、游戏全屏、演示模式。

## 7. CI 质量门禁

本节定义最低质量门槛；具体 PR、Nightly、Beta、Stable 流程和风险分级遵循[开发流程与交付规范](10-development-workflow.md)。

每个 PR：

- restore/build/test 可重复通过。
- 格式和静态分析无新增告警。
- 依赖漏洞与许可证检查。
- Core 单元测试和配置迁移测试。
- 生成可安装的临时包或至少完成打包验证。

每日/发布前：

- UI 冒烟、多 DPI 截图差异。
- 布局随机化/属性测试。
- 强杀与配置恢复测试。
- 长时间资源泄漏测试。
- 安装、升级、卸载和回滚。
- 生成 SBOM 并对二进制签名。

## 8. 发布阻断条件

出现以下任一情况不得发布：

- 可导致用户文件丢失、误删除或不可逆移动。
- 配置损坏后无恢复路径。
- 普通使用要求管理员权限。
- 已知高危依赖漏洞。
- 未经同意发送敏感数据。
- 多显示器切换后大规模丢失布局。
- 显示器映射歧义时仍自动或部分提交布局。
- 新显示变化已经开始后仍提交旧代次恢复计划。
- 批量窗口应用失败或结果不一致后仍宣称恢复成功，或未经验证就丢弃回滚快照。
- 回滚失败后继续自动重试窗口移动，造成布局震荡或覆盖诊断现场。
- 隐藏消息窗口出现在 Alt+Tab/任务栏、抢焦点，或 WTS/Timer/窗口类未成对注销。
- 在线程池工作线程反复创建 DPI 探测 HWND，导致 USER 消息队列上限随线程数漂移。
- 安装包未签名或升级无法回滚。
