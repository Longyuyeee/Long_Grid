# Long方格（Long Grid）产品需求文档（PRD）

版本：0.4
状态：Draft
首个技术预览目标：Windows 11 x64；Windows 10 与 ARM64 在后续矩阵通过前不作承诺

面向用户的中文产品名为 **Long方格**，英文品牌名为 **Long Grid**；代码和程序集继续使用 `LongGrid`。完整视觉、图标、动效和交付合同见[视觉品牌、动效与交付要求](14-visual-branding-and-delivery-requirements.md)。

## 1. 产品愿景

帮助用户在 10 秒内从混乱桌面进入清晰、可恢复的工作状态，同时不夺取用户对文件的控制权。

## 2. 目标用户

### A. 多项目知识工作者

桌面上混合客户资料、截图、下载文件和应用快捷方式，需要按项目快速切换上下文。

### B. 学生与创作者

文件数量多、分类习惯不稳定，希望低成本自动整理，又不希望软件改变真实目录结构。

### C. 多显示器重度用户

频繁连接/断开显示器，最在意布局保持、性能和稳定性。

### D. 演示与共享屏幕用户

需要一键隐藏敏感或杂乱内容，并能迅速恢复。

## 3. 核心任务

1. 在 Windows 桌面空白处右键创建盒子，并直接移动、缩放、重命名、折叠、锁定、删除和设置外观。
2. 将盒子绑定到一个真实文件夹，在桌面浏览和管理其中的文件与文件夹。
3. 使用可视化预设美化系统任务栏，并能可靠恢复系统默认。
4. 从 Explorer 拖入项目、在盒子之间改变归属，并清楚区分引用和真实文件移动。
5. 在三项核心稳定后增加自动整理、布局恢复、快速隐藏、工作空间、小组件和插件能力。

## 4. MVP 范围

### P0 功能

#### 容器

- 桌面空白处右键菜单必须提供“新建 Long方格盒子”；与控制中心、快捷键和拖画入口共用同一创建命令和事务。
- 创建、命名、移动、缩放、删除容器。
- 标题显示、颜色、透明度、紧凑/展开状态。
- 锁定位置，防止误拖。
- 容器内项目支持键盘和鼠标操作。

#### 项目入口

- 支持快捷方式、文件、文件夹和 URL。
- 默认保存引用，不移动原始文件。
- 文件丢失或路径变化时显示可恢复的错误状态。
- 所有项目至少提供类型图标；实时缩略图只能在隔离 Worker 成功时显示，失败必须安全回退。

#### 文件夹绑定盒子

- 用户可以为盒子选择、绑定、显示和解绑一个本地或受支持的重定向文件夹；绑定不会移动文件夹或改变其磁盘位置。
- 盒子直接显示绑定目录内容，并支持刷新、滚动、排序、选择、键盘导航和按系统方式打开。
- 必须显示当前绑定路径和正常、空、加载、失效、离线、权限拒绝、恢复状态；状态变化不能导致界面卡死或弹窗风暴。
- 大目录、云占位符、网络路径和文件监控风暴必须有限处理；首个 Core 版本可以限制规模，但必须明确说明而不能截断后伪装成功。
- 多目录标签、复杂面包屑、批量真实文件移动和高级 Portal 文件操作属于后续增强，不阻挡单文件夹绑定盒子的 Core 交付。

#### 桌面整理模式

- 必须枚举当前用户桌面、Public Desktop 和受支持的重定向桌面位置。
- 首版只提供“安全引用模式”，不移动文件；首次使用必须说明原生桌面图标可能仍然存在。
- 托管目录模式、真实文件移动和真实文件自动整理移至 P1 以后单独立项。
- 原生 Explorer 图标的空间分组属于 Phase 0 实验能力，未验证前不作为 MVP 承诺。
- 产品界面必须始终区分“改变 Long Grid 归属”和“移动磁盘文件”。

#### 自动整理

- 条件：扩展名、项目类型、名称模式、创建时间。
- 动作默认是“建议归类”，不自动移动真实文件。
- 预览命中项、冲突和最终效果。
- 应用后提供撤销。

#### 布局

- 自动保存与手动快照。
- 按显示器拓扑、工作区和缩放保存坐标。
- 断电/崩溃安全写入。
- 恢复前显示差异；失败时回退最近有效快照。

#### 快速访问

- 可配置全局快捷键显示/隐藏 Long Grid。
- 双击桌面隐藏功能仅在技术验证证明不破坏系统习惯时启用。
- 托盘入口包含显示、隐藏、暂停规则、设置和退出。

#### 设置与引导

- 首次启动明确解释“引用”与“移动”的区别。
- 开机启动默认由用户选择。
- 导入/导出本地配置。
- 当前已落地 current-v1、本地文件系统、用户显式确认的受限导入/导出，以及匿名证据清单、单项原始证据导出、观察容量/最早时间和用户确认的单项永久清理；schema 迁移等待真实 v2 字段准入，云端目标、自动保留期限、容量阈值和批次清理继续延期。
- 诊断页显示版本、日志位置、显示器拓扑和恢复状态。
- 首版完全本地运行，不要求账户，不进行持续网络轮询。
- 正式安装渠道目标为 MSIX，并保留企业离线 MSIX 验证；当前 unpackaged 入口仅用于开发。

#### 产品壳层与信息架构

- 正式应用必须表现为桌面管理控制中心，不得把教程、Design Token、开发状态、证据门槛或安全审计作为一级产品导航。
- 桌面是日常创建、拖放、打开、折叠和隐藏的主表面；控制中心只承担概览、批量管理、规则、布局恢复、个性化和设置。
- MVP 控制中心使用稳定的“桌面概览、方格管理、自动整理、布局与恢复、个性化、设置”结构；未实现模块在发布构建中隐藏，不使用大面积禁用占位页。
- 页面顶部采用明确的任务标题、简短说明和一个主操作；首屏直接显示真实方格、项目、规则或布局状态。
- 首次教程只在首次启动出现，允许跳过，完成后退出常驻导航；安全说明应在相关操作位置以普通用户语言出现。
- 诊断、证据、版本和内部状态进入“设置 → 高级诊断”，默认折叠，普通用户文案不得暴露 revision、generation、CAS、UIA 或 HDROP 等工程术语。
- 产品壳层和执行顺序以[统一开发计划](PRODUCT_EXECUTION_PLAN.md)为当前权威来源。

#### 视觉、动效与品牌

- 正式 UI 采用现代化、扁平化、精致华丽但简约的视觉风格；华丽来自克制的层次、色彩、材质和动效，不来自持续高资源特效。
- 使用统一 Design Token，支持浅色、深色、系统强调色、高对比度、文本缩放和减少动画。
- 常规状态动效平滑、可中断、可降级；拖动和缩放必须直接跟手，空闲状态不得持续播放装饰动画。
- 应用图标将字母 L 与方格融合为单一几何符号，保持扁平、现代、简约，并提供 SVG、ICO、MSIX 和全尺寸像素校正版。
- 第一个生产切片必须提供正式 UI Shell、一键开发启动入口和可复现的未签名开发包。

#### 任务栏美化

- 任务栏美化是 Core 功能，不是小组件或生态附属项；入口位于“个性化 → 任务栏”。
- 首版使用预设优先：系统默认、清透、深色半透明、浅色半透明，以及仅在支持环境显示的 Acrylic。
- 应用预设必须先临时生效并提供 15 秒“保留/恢复”确认；失败、超时或失去宿主时恢复系统默认。
- 必须检测 Windows build、多显示器、Explorer 重启和已知第三方任务栏修改工具冲突；不支持时明确拒绝并解释原因。
- 任务栏适配器必须与 DesktopHost 和主 App 隔离故障域，提供托盘和设置页一键恢复；关闭、崩溃、禁用与卸载路径必须验证恢复。
- 不注入或 Hook `explorer.exe`，不修改 Explorer 内部 XAML，不以高风险深度换肤作为 Core 依赖。

### P1 功能（V1）

- 高级 Folder Portal：多目录标签、面包屑、复杂视图和经单独授权的文件操作；单文件夹绑定盒子属于 P0。
- 托管目录模式及经过独立授权、预览和补偿设计的真实文件移动。
- 项目工作空间：一键启动应用并恢复窗口布局。
- 容器标签页、卷起、搜索和最近使用排序。
- 更丰富规则：目标路径、来源目录、正则、大小、年龄。
- 规则模拟器与冲突优先级。
- ARM64 原生包。
- 高级协调外观：让盒子、壁纸色板与任务栏预设形成可保存主题；任务栏基础预设属于 P0。

### P2 功能（V2+）

- 桌面小组件与受权限约束的 Widget SDK。
- 兼容 Long助手 `.lpak` 插件包：命令插件可包装为快捷动作卡，声明 Widget Surface 的 Web 插件可作为原生小组件。
- 原生 DLL、C# Script 和 Hybrid 高信任插件默认不得嵌入 Long Grid 核心进程。
- 跨设备同步，但采用端到端加密且可完全关闭。
- 可选本地语义分类。
- 团队共享模板与企业策略。

## 5. 明确不做

- MVP 不提供壁纸商城、天气服务、截图工具或系统清理。
- MVP 不注入或 Hook `explorer.exe`，不替换系统任务栏。
- MVP 不上传桌面文件名、路径、缩略图或内容。
- MVP 不提供自研加密保险箱。
- 不替换 Explorer，不注入第三方进程，不安装内核驱动。
- 不用“AI”替代可解释的基础规则。

## 6. 关键交互规则

完整的信息架构、首次启动、桌面模式、容器状态、拖放反馈、自动整理、恢复、任务栏、小组件和工作空间交互，以[交互设计审计与体验规范](09-interaction-design-audit.md)为准。

### 首次启动

- 首次扫描只读，并明确显示“尚未修改任何文件”。
- 提供“一键建议”和“从空白开始”两条路径。
- 一键建议必须先进入布局预览，不能直接应用。
- 账户、订阅、壁纸、插件和小组件不得阻塞首次整理。
- 首次应用后只教学创建、拖放语义和撤销三个动作。

### 删除容器

删除容器只删除 Long Grid 的组织关系，不删除磁盘文件。若未来提供真实文件移动，必须使用独立、明确的操作文案。

### 拖放

- 从 Explorer 拖入：默认创建引用。
- 按住修饰键请求移动/复制：必须显示目标路径和确认。
- 从一个容器拖到另一个：只改变组织关系。
- 无效目标：保持原状并给出原因。

### 自动整理

```text
检测新项目 → 规则计算 → 生成建议 → 用户确认/自动策略 → 写入操作记录 → 可撤销
```

自动策略必须按规则单独授权；全局“全部自动移动”不作为默认选项。

## 7. 成功指标

### 体验

- 新用户首次创建容器并加入项目：中位数 < 2 分钟。
- 从隐藏状态唤起：P95 < 300 ms。
- 100 个项目的布局恢复：P95 < 1 秒，不含网络目录访问。
- 常用任务可全键盘完成。

### 稳定性

- 7 日无崩溃会话率 ≥ 99.8%（公开测试期目标）。
- Explorer 重启后自动恢复成功率 ≥ 99%。
- 已识别显示器拓扑的布局恢复成功率 ≥ 99%。
- 布局持久化不得产生不可恢复的数据损坏。

### 资源

- 空闲 CPU 目标 < 0.2%（5 分钟均值，基准机）。
- MVP 空闲专用内存目标 < 120 MB；Phase 0 后根据技术栈修订。
- 不启用壁纸/小组件时不得存在持续网络轮询。

## 8. MVP 验收场景

1. 在 100%、150%、200%、300% 缩放间切换，容器不漂移出可视区域。
2. 拔掉副屏再接回，布局恢复且不会把全部项目堆到主屏。
3. `explorer.exe` 重启后，Long Grid 自动恢复且不重复创建项目。
4. 进程在保存中被终止，重启后加载最近有效配置。
5. 同名文件、失效快捷方式、OneDrive 占位文件和离线网络目录不会导致卡死。
6. 快捷键与系统或其他应用冲突时可检测并更换。
7. 删除容器后，磁盘上的所有原文件保持不变。
8. 屏幕阅读器能读出容器名称、项目名称、状态和操作。
9. 安全引用模式明确提示可能的原生图标重复；首版没有真实文件移动入口。
10. 首次启动的一键建议在用户确认前不改变文件或布局，并能从预览完整退出。
11. 用户可从桌面空白处右键创建盒子，并能在不进入教程页的情况下完成改名、移动、缩放和外观设置。
12. 盒子绑定真实测试文件夹后显示权威内容；解绑、路径失效、权限拒绝和恢复均不移动或删除原文件。
13. 每个受支持任务栏预设都能临时应用、确认保留并一键恢复；Explorer 重启、进程崩溃和卸载测试后系统任务栏恢复到明确状态。

## 9. 已批准范围与延期项

2026-08-04，项目负责人以 `ProjectOwner` 代号批准 D23-01–D23-10：仅安全引用、本地无账户、Folder Portal/ARM64 后移、Windows 11 x64 技术预览、MSIX 目标渠道、类型图标安全回退、接受原生 Explorer 图标共存、保留首片性能门禁，并让 ADR-0001 在人工/硬件证据完成前保持 `Proposed`。

2026-08-25，项目负责人重新明确产品核心为“桌面右键创建和管理盒子、盒子绑定文件夹、任务栏美化”。该决策仅覆盖并修订上述“Folder Portal 后移”和任务栏 P1 优先级：单文件夹绑定盒子与基础任务栏预设升为 P0 Core；高级多目录 Portal、深度任务栏换肤、LongBar、小组件和插件继续后移。安全引用、本地无账户、不注入 Explorer 和恢复门禁保持不变。

许可证与商业模式（D23-11）按负责人要求延期，不阻挡当前开发；仓库不新增 `LICENSE`，正式分发或接受外部贡献前必须重新处理。品牌最终商店素材仍在发布准备阶段确认。
