1. 项目负责人提供一个已经登录的无个人内容专用 Windows 11 x64 测试账户或可抛弃 VM；若要由自动化创建临时本地账户、启用虚拟化或改变电源策略，必须另行明确授权并在提升会话中执行；

3. 固定 `faafe2d` 的代码、预算和配置，先运行采集器与复审器的 `-ValidateOnly`；
4. 启动完整 24 小时会话，期间任何 App 退出、采样中断、休眠、重启或环境失控均记为 Inconclusive；
5. 对原始证据用同一 commit 独立复审。只有得到 `EligibleForM4cDecision` 并完成人工环境/异常审计，才能另开切片裁决 M4c；失败或修复后必须从新 commit 重跑完整 24 小时；
6. M4c 裁决完成后仍按 Stage 129 的 X1 → X2 → X3 → X4 → X5 顺序汇合人工、输入/Narrator、动态显示、真实卷和 Phase 0/ADR 证据。
