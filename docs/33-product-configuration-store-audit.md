## 3. 边界与安全判定

- “原子”仅指同一文件系统目录中的应用级发布边界；不承诺所有磁盘、文件系统或断电场景具有相同耐久性。
- 主文件损坏但备份有效时只返回 `RecoveredFromBackup`，不会自动覆盖或删除原始损坏证据。
- 主配置不可用而备份有效时，用户可经默认取消的二次确认接受备份；原备份保持不变，损坏主配置归档为独立证据。主备均不可用或上次重置中断时，用户可经同级确认创建标准空白配置，并按实际存在情况分别归档主备证据。后续切片已支持当前 v1 本地 JSON 的受限导入/导出和匿名证据清单；schema 迁移与证据原文导出/保留/清理尚未实现，因此仍不能描述为完整配置迁移/修复流程。
- 写租约只串行化配置提交，不等同于应用单实例；后续独立切片已用 AppLifecycle 完成激活转发、进程所有权与第二实例退出。
- 本轮没有修改真实卷、ACL、系统设置、任务栏或 Explorer。
