# Phase 0 Technical Spikes

本目录保存已经执行的技术探针报告。每份报告必须区分：

- 已验证事实；
- 只在当前机器观察到的结果；
- 尚未覆盖的范围；
- Pass/Conditional Pass/Fail/Inconclusive；
- 后续探针和 ADR。

探针工作项使用 `.github/ISSUE_TEMPLATE/technical-spike.md`，执行流程见[开发流程与交付规范](../10-development-workflow.md)。
