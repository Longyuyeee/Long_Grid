# 竞品研究与机会地图

研究日期：2026-07-29
方法：只采用公开产品页、官方文档和公开仓库信息；功能名称不代表我们应复制其实现。

## 1. 市场基准

### iTop Easy Desktop

公开页面展示的核心组合是：

- 自动按类型整理桌面图标。
- 盒子/分组、文件夹入口与密码保护的私密盒子。
- 静态/动态壁纸、主题与一键个性化。
- 日历、便签、天气等桌面组件。
- 窗口、全屏和滚动截图。
- 双击隐藏图标、布局快照及新文件提示。

它的优势是“一站式”和低学习成本，风险是功能面过宽、常驻模块较多，且安全、隐私和性能更难建立信任。Long Grid 应吸收其顺滑的新手体验，但不应在 MVP 同时制作壁纸库、天气、截图和私密保险箱。

来源：[iTop Easy Desktop 产品页](https://www.itopvpn.com/itop-easy-desktop)、[iTop Easy Desktop Pro 功能页](https://www.itopvpn.com/easy-desktop-newplan)

### Stardock Fences

其成熟能力包括：

- 可定制的桌面分组及规则自动归类。
- Folder Portals，把真实文件夹映射为桌面入口。
- Peek 快速置顶、卷起、标签页、快速隐藏。
- 按类型、名称、时间、目标等条件自动整理。
- 布局快照、显示器变化适配和高 DPI 支持。
- 颜色、透明度、图标色调及降噪模式。

最值得学习的不是视觉，而是对多显示器、DPI、Explorer 异常、网络目录和布局恢复的长期投入。这些是桌面工具真正的护城河。

来源：[Stardock Fences 官方页](https://www.stardock.com/products/fences/index)、[Fences 更新历史](https://www.stardock.com/products/fences/history)

### Nimi Places

Nimi Places 长期聚焦于把桌面内容组织到容器中。其启示是：一个聚焦、快速、可自定义的核心体验本身可以长期成立，不必一开始扩张为“系统工具全家桶”。

来源：[Nimi 官方站](https://mynimi.net/)

### Portals

Portals 是公开的 Windows 桌面组织项目，定位为免费、轻量、可自定义。它说明“文件夹入口 + 轻量容器”对开源用户有明确吸引力，也可作为交互与兼容性测试的参考对象；使用其代码前必须单独核查许可证和具体实现。

来源：[Portals GitHub 仓库](https://github.com/Ross-Patterson/Portals-Desktop-Organization)

### Microsoft PowerToys Workspaces

Workspaces 关注的是“任务上下文”而非图标：捕获应用及窗口位置，一键启动/恢复项目工作台，可为应用增加启动参数并创建快捷方式。

这揭示了更大的机会：Long Grid 的分组不应只是静态盒子，而可以逐步升级为“项目空间”，同时包含文件入口、应用、窗口布局和规则。

来源：[PowerToys Workspaces 官方文档](https://learn.microsoft.com/windows/powertoys/workspaces)

## 3. 用户未被充分满足的需求

1. **自动化可控**
   用户希望自动整理，但害怕文件被移动。解决方案是“建议模式”：先显示命中结果和变更预览，用户确认后应用；每次操作均可撤销。

2. **显示器变化后仍可信**
   笔记本在办公室、家庭、投影和远程桌面之间切换时，布局应按显示器拓扑自适应并能解释恢复结果。

3. **从图标盒子升级为项目上下文**
   一个“设计项目”空间可同时包含文件夹入口、常用应用、URL、窗口布局和临时收件箱。

4. **真正的轻量与隐私**
   核心整理无需账户、广告、云服务或后台下载。遥测默认关闭或最小化，并提供一键导出诊断信息。

5. **无障碍不是补丁**
   键盘创建/移动/调整容器，屏幕阅读器可读，支持高对比度、文本缩放和减少动画。

## 4. 建议定位

> Long Grid 是一个本地优先、可撤销、面向项目上下文的 Windows 桌面工作空间。

差异化支柱：

- **可靠**：多显示器、DPI、Explorer 重启和异常断电后布局仍可恢复。
- **可控**：任何自动整理都可预览、解释、撤销。
- **聚焦**：MVP 只做整理、入口、快照和快速访问。
- **可扩展**：后续用受限插件扩展小组件和规则，不把所有功能塞进核心进程。

## 5. 不应照搬的内容

- 竞品名称、图标、截图、主题、文案和交互细节。
- 未经许可的私有 API、注入方式、协议或反编译实现。
- 为追求功能数量而加入壁纸下载、天气、截图、清理、VPN 等不相关模块。
- 未完成威胁建模就承诺“保险箱级安全”。

桌面呈现形态、任务栏预设及其底层技术路线的进一步拆解，见[桌面管理与任务栏美化深度审计](06-desktop-taskbar-audit.md)。
