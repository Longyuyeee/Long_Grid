## 3. 风险清单

### P0：立项前必须处理

1. **文件安全风险**
   自动整理若直接移动真实文件，可能破坏用户路径、快捷方式、同步软件和工作流。MVP 默认只管理“视觉归属与布局”，任何真实文件移动必须显式确认、展示目标位置并可撤销。

2. **Explorer 与桌面层兼容风险**
   Windows 桌面并非普通应用画布。Explorer 重启、虚拟桌面、任务栏变化、壁纸切换、全屏程序和“显示桌面”都可能破坏覆盖层或交互。

3. **多显示器与 DPI 风险**
   显示器休眠、拔插、旋转、主屏切换、分辨率变化及 100%–400% 缩放必须被视为核心场景，而非后期适配。

4. **技术栈未经验证**
   WinUI 3 适合现代设置界面，但桌面容器仍需 Win32/COM/窗口管理互操作。应通过探针验证，不应仅凭 UI 偏好定案。

5. **许可和品牌风险**
   仓库没有许可证；“对标”不能变成复制竞品资产或文案。正式接受外部贡献前需确定许可证和贡献协议。

### P1：MVP 前处理

- 单实例、开机启动与升级失败回滚。
- 布局文件损坏后的恢复策略。
- 全局快捷键冲突检测。
- 性能预算、崩溃转储与本地日志脱敏。
- 键盘操作、屏幕阅读器、高对比度和减少动画。
- 卸载后是否保留配置及明确提示。

### P2：公开测试前处理

- 安装包签名、SmartScreen 声誉和发布渠道。
- 崩溃收集与遥测的明确授权。
- 本地化、RTL、长文本和输入法验证。
- 第三方依赖清单、SBOM、漏洞扫描。

## 4. 建议仓库结构

```text
Long_Grid/
├─ src/
│  ├─ LongGrid.App/              # WinUI 设置、引导与托盘 UI
│  ├─ LongGrid.DesktopHost/      # 桌面容器与窗口宿主
│  ├─ LongGrid.Core/             # 领域模型与用例
│  ├─ LongGrid.Infrastructure/   # 持久化、Shell/Win32 适配
│  └─ LongGrid.Contracts/        # 进程间/插件契约
├─ tests/
│  ├─ LongGrid.Core.Tests/
│  ├─ LongGrid.IntegrationTests/
│  └─ LongGrid.UiTests/
├─ tools/                        # 开发、诊断和打包工具
├─ docs/
│  ├─ adr/
│  └─ ...
├─ assets/                       # 自有品牌与商店素材
├─ .github/workflows/
├─ Directory.Build.props
├─ Directory.Packages.props
├─ LongGrid.slnx
└─ README.md
```

MVP 可先采用同进程模块化单体，只有当桌面宿主崩溃隔离或权限边界有明确收益时再拆进程。不要为了“架构完整”提前引入微服务或云后端。

## 5. 工程基线建议

统一执行流程、风险分级、DoR/DoD、探针证据、PR、测试和发布渠道现已定义在[开发流程与交付规范](10-development-workflow.md)，贡献入口见仓库根目录 `CONTRIBUTING.md`。

### 必须

- 使用受支持的 .NET LTS 与 Windows App SDK Stable 通道，并锁定 SDK/依赖版本。
- 启用 nullable、警告视为错误、格式检查和静态分析。
- 单元测试覆盖规则引擎、布局换算、序列化迁移和撤销栈。
- PR 至少执行 restore、build、test、format、依赖漏洞扫描。
- 配置文件使用带版本的 schema；写入采用临时文件 + 原子替换 + 备份。
- 所有文件系统副作用通过统一接口执行并记录可撤销操作。

### 建议

- 使用 Conventional Commits 或同等清晰的提交规范。
- 维护 ADR，不在聊天记录里做长期技术决策。
- Nightly 产出未签名开发包；Release 仅由受保护标签触发。
- 发布包含哈希、变更日志、SBOM 和回滚说明。
