# Long方格品牌概念资产

状态：**概念评审，不是最终商标或发布资产**

本目录保存 Long方格“L + 方格”图标的原创矢量探索。候选源文件位于 `concepts/`，总览见 `longfangge-icon-concepts.svg`。

经负责人确认继续后，A“结构化 L”已进入 [`rc1/`](rc1/) 做多尺寸与主题校正；RC1 仍不是最终商标或公开发布资产。

## 当前候选

| 候选 | 方向 | 当前判断 |
|---|---|---|
| A | 结构化 L | 首选；L 与网格共享同一套单元体系，识别与扩展最均衡 |
| B | 负空间 L | 深色辨识强，但 16 px 内部结构偏密 |
| C | 开放式方格 L | L 最直接，但独立格子略像附加元素 |
| D | 模块化转角 | 桌面模块感明确，但整体凝聚力较弱 |

在负责人批准前，不得把任何候选写入安装包、应用清单、任务栏、商店素材或宣传页面。下一轮只对候选 A 做像素校正、单色/深色/高对比变体和 Windows 外壳实机检查。

详细评分、风险和需求追踪见 [`docs/15-icon-concept-audit.md`](../../docs/15-icon-concept-audit.md)。
